Key Design Decisions

  • ReportAssembler is the single entry point — both templates consume the same payload
  • Templates live in templates/ directory — design changes never touch Python
  • Export endpoints are GET (idempotent download), not POST — narrative must be generated first
  • All rendering runs in asyncio.to_thread() to avoid blocking the event loop
  • Files stream from BytesIO — nothing written to disk
